## Команды

```bash
cd /workspace/dkosenkovv/motion-lab
npm ci
cd demo
bash ../scripts/hf.sh check --json
bash ../scripts/hf.sh snapshot --at 0,2.5,7.5,12.5 --describe=false
bash ../scripts/hf.sh preview --background --port 3004
bash ../scripts/hf.sh render --quality delivery --workers 2 --output out/aibasis-motion-demo.mp4
```

Wrapper хранит history/font/extract кэши под /workspace/.cache, использует уже установленный Chromium и отключает необязательную телеметрию. В облаке доступен программный GPU, так что рендер медленнее аппаратного. `doctor.ok=false` обусловлен необязательными whisper-cpp/Kokoro/MusicGen; локальный MP4 не зависит от них. Распознавание речи и rembg ранее настроены отдельно в video-studio. Платные HeyGen, Figma и внешние аккаунты не подключались.

Персональный бренд-файл нельзя считать завершённым, пока пользователь не предоставит неизвестные данные. Проверенная техническая анимация использует явно обозначенный fallback-профиль.
