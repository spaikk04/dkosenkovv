# Video Studio

Рабочий проект для продуктовых и экспертных роликов. Node 24, React 19, Remotion 4.0.538. Установлены Three.js, React Three Fiber, Drei, Motion, GSAP, PixiJS, Lucide, Lottie и модули Remotion для медиа, титров, форм и переходов. Версии закреплены в package-lock.json.

## Команды

Рабочий каталог: `/workspace/dkosenkovv/video-studio`.

```bash
bash scripts/setup.sh     # повторная установка Node/Python-зависимостей и проверка модели
npm run dev               # запуск Remotion Studio; процесс нужно запускать заново в новой задаче
npm run lint              # ESLint и TypeScript
npm run build             # сборка
npm run render:smoke      # 2 секунды H.264/AAC с настоящим 3D, титрами и иконками
npm run still:smoke       # PNG кадра 30
/workspace/.venvs/video-tools/bin/python scripts/remove-background.py input.jpg output.png
```

Chromium и FFmpeg уже доступны в облачном базовом образе. Конфигурация использует `/usr/bin/chromium`, программный 3D-рендер `swangle` и два параллельных потока. На другой ОС пути и режим GPU нужно адаптировать. Кэш npm — `/workspace/.npm-cache`; Python-окружение — `/workspace/.venvs/video-tools`; модель — `/workspace/.cache/u2net`. Они не включаются в Git. Использовать существующий checkout; новая рабочая копия или worktree не требуется.

## Что проверено

- `npm ci`, дерево зависимостей без конфликтов, ESLint, TypeScript и сборка.
- Studio возвращает HTML приложения по локальному HTTP-запросу.
- `ToolkitCheck`: 60 кадров, 640×360, 30 fps, экспорт H.264/AAC; визуально проверен PNG с 3D, иконками и кириллицей. Аудиопоток декодируется, содержит тестовый затухающий тон.
- rembg 2.0.86 + CPU ONNX Runtime, локальная модель U2NetP; хеш совпадает с upstream; обработка изображения выдала RGBA с альфой от 0 до 255. Это техническая проверка, не оценка качества вырезания волос на исходном видео. Для видео нужна отдельная обработка кадров и проверка временной стабильности маски.

Выходные файлы находятся в `out/` и исключены из Git. Тестовая композиция проверяет инструменты, а не является готовым монтажом по пользовательскому референсу. Motion, GSAP, PixiJS и Lottie установлены, но отдельные эффекты каждой библиотеки в этой проверке не рендерились. В Remotion анимация должна зависеть от кадров, а не от автономного CSS/JS-таймера.

Magic UI — коллекция копируемых компонентов, а не обязательная зависимость видеодвижка; выбирать компоненты следует под конкретную сцену. Aseprite и альтернативный движок Motion Canvas для этого workflow не нужны и не установлены. Платные плагины, сервисы и ассеты не приобретались. Условия Remotion и GSAP отличаются от MIT; лицензии шрифтов, музыки, моделей и готовых анимаций проверяются отдельно.

Исходный scaffold: `remotion-dev/template-empty`; последующие файлы адаптированы для этой облачной среды. Python-зависимости зафиксированы в `requirements-video-tools.txt`. Скиллы и их исходные версии хранятся рядом, в `../.agents/skills/`.
